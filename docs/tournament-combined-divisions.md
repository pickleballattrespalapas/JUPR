# Combine tournament divisions into one draw

Use **Live Operations → Draw setup & recovery → Combine divisions** when two
registration divisions will play together, such as Mixed 4.0 and Mixed 4.5.

1. Select the draw that will become the combined draw. If neither division has
   a draw, create an empty draw for either division first.
2. In **Combine divisions**, select the other division and review the combined
   draw name, for example **Mixed / 4.0 / 4.5**.
3. Confirm **COMBINE DIVISIONS**. Existing teams in the selected draft draws move
   into the selected draw. The other draft draws are retained as retired records.
4. Use **Import confirmed registrations** with **APPEND** to include any teams
   that have not been imported. Existing complete pairs are kept once, including
   teams entered manually. A conflicting pairing must be corrected first.
5. Review the combined roster and seeds. Set up pools if desired, generate the
   round-robin games, and activate the combined draw in the Day workspace.

The draw has one schedule, one playoff, and one podium. Pool assignment and
manual playoff-qualifier review work as they do for any other draw. Paper match
cards, tally sheets, and public results use the combined draw name. Tournament
closeout recognizes every included registration division as covered.

Original registration divisions, locked registration ratings, partner links,
and payments are preserved. The combined draw does not award separate medals
for each original division.

Combine before generating games or entering live operations. Remove saved pool
assignments before combining. Divisions must be enabled standard singles or
doubles events of the same family, gender, and format on the same owning day.
Combined-rating-cap and four-player team events are excluded. Duplicate players
across source teams must be resolved before combining.

An existing combined draw can include additional compatible divisions before
play. Its saved source divisions cannot be unchecked. To add another division,
select that combined draw as the destination.
